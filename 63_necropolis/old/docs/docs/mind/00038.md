# Phase 45: Σ-CORE The Genesis Run (Autonomous Cybernetics)

## Контекст (Context)
Фізичний, біологічний та мережевий субстрати OMEGA-64 повністю завершені. Тепер ми маємо перетворити проєкт із "симулятора, який ми запускаємо вручну" на автономний, самодостатній кібернетичний тераріум. LLM-Оракул повинен отримати власний асинхронний пульс (серцебиття), щоб самостійно читати літопис світу і скидати плазміди без нашого втручання. Матриця має працювати 24/7.

## Крок 1: Автономний Пульс Оракула (The Oracle Loop)
У `SOVEREIGN_ORACLE.ts` або `SYSTEM_START.ts`:
1. Створи автономний цикл `startAutonomousOracleLoop(intervalMs)`.
2. Раз на N хвилин (або кожні 10,000 тактів Матриці) цикл автоматично "прокидається".
3. Він збирає поточний `STATE_MATRIX` (кількість атомів, кількість Мембран, середню Ентропію, розміри Некрополісу) та останні записи з `AKASHA_CODEX`.
4. Формує промпт для LLM (Gemini/OpenAI): "Ось стан твого світу. Напиши одну 8-байтну плазміду, щоб змінити хід історії".

## Крок 2: Інтеграція Паноптикуму (The Observer's UI)
Оскільки система тепер житиме сама, нам потрібен зручний спосіб за нею спостерігати.
У `PANOPTICON_SERVER.ts` (або просто в консольному виводі Deno):
1. Налаштуй красивий стрімінг логів епох. 
2. Коли Оракул робить ін'єкцію, або коли велика Мембрана вмирає і стає Руїною, система має генерувати читабельну подію: `[EPOCH 42] The Oracle dropped a Plasmid (Entropy: 1.2). A Metazoan at (45, 80) has collapsed into Ruins.`

## Крок 3: The Genesis Gate (Безперервний Тест)
У `tests/test_genesis_run.ts`:
1. Запусти `SYSTEM_START` у режимі `--genesis` або `--autonomous`.
2. Замокай (mock) відповідь від LLM-API, щоб тест не витрачав реальні токени, але повертав валідну hex-плазміду.
3. Прокрути симуляцію на 50,000 тактів.
4. Перевір (`assert`), що автономний цикл Оракула успішно спрацював мінімум 2 рази, ін'єктував плазміди, система не впала через витоки пам'яті (Memory Leaks), і `AKASHA_CODEX` успішно записав історію.

## Правила (Constraints)
- Оракул має працювати асинхронно і НЕ блокувати головний цикл `PULSE_WORKER`. Фізика (WASM) повинна продовжувати тікати на швидкості 60 FPS, поки LLM "думає" над відповіддю (що може займати 2-5 секунд).
- Граціозне завершення: при натисканні `Ctrl+C` система повинна акуратно зберігати останній зліпок (Genesis Block) на диск перед вимкненням.
