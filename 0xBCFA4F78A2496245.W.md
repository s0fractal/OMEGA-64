## GREEN (G)

The W Combinator, also known as the Warbler or the Duplication operator.
Duplicates the second argument and passes both instances to the function `f`.

## BLUE (B)

```typescript
/**
 * W: Duplication Combinator

export const ATOM = () => (f: any) => (x: any) => f(x)(x);
```
