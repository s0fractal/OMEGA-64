# Phase 47: Σ-CORE The Panopticon UI (Visualizing the Swarm)

## Контекст (Context)
Бекенд OMEGA-64 працює автономно в режимі Genesis Run. Нам потрібен легковаговий клієнтський фронтенд (HTML5 Canvas або WebGL), який підключатиметься до `PANOPTICON_SERVER.ts` через WebSocket і рендеритиме `STATE_MATRIX` у реальному часі. Ми маємо нарешті побачити анатомію нашого Всесвіту: мембрани, руїни, мітохондрії та плазміди.

## Крок 1: WebSocket Телеметрія
У `PANOPTICON_SERVER.ts`:
1. Налаштуй WebSocket-ендпоінт (наприклад, `ws://localhost:8000/stream`).
2. Сервер має раз на N тактів (наприклад, 10 разів на секунду) серіалізувати найважливіші дані зі `STATE_MATRIX` (координати атомів, їхні ролі, зв'язки `bonds`, `STRUCTURE_GRID`, `memory_grid`) і відправляти їх підключеним клієнтам у стислому бінарному або JSON форматі.

## Крок 2: HTML5 Canvas Рендерер
Створи теку `public/` та файл `index.html` (із вбудованим або зовнішнім JS):
1. Ініціалізуй Canvas розміром відповідно до `spatialGrid` (наприклад, 1400x800 для сітки 140x80).
2. Налаштуй WebSocket з'єднання для отримання кадрів від сервера.

## Крок 3: Правила Візуалізації (The Aesthetics)
Напиши функцію `drawFrame(state)`, яка розфарбовує Матрицю:
1. **Некрополіс (Руїни):** Клітинки зі `STR_WIRE` чи `STR_NODE` малюються як статичні сірі/білі блоки (камінь).
2. **Атоми (За Ролями):** - `ROLE_GUARDIAN` (Мембрана/Шкіра): Червоні або помаранчеві квадрати.
   - `ROLE_ARCHITECT` (Ядро): Сині або фіолетові квадрати, що світяться (можна додати пульсацію).
   - `ROLE_MITOCHONDRIA` (Ендосимбіонти): Маленькі зелені крапки, які рендеряться *поверх* Архітекторів (щоб показати симбіоз).
   - `ROLE_PRODUCER` (Вільні агенти): Жовті або білі точки.
3. **Зв'язки (Bonds):** Якщо між атомами є зв'язок, малюй напівпрозору лінію. Це дозволить побачити Мембрани як замкнуті полігони!
4. **Плазміди:** Якщо в `memory_grid` є плазміда, малюй яскравий ціановий (cyan) гліф на цій клітинці.

## Крок 4: Панель Літопису (The Codex Overlay)
На фронтенді додай текстовий блок збоку або знизу екрана:
1. Виводь туди останні `narrativeMood` від Оракула (з `AKASHA_CODEX`). 
2. Показуй глобальну Ентропію та кількість живих атомів.
