# Phase 54: Context Distillation (The Holographic Exporter)

## Контекст (Context)
Наразі наш скрипт генерації маніфесту та експорту коду створює єдиний величезний файл (`OMEGA_CORE_LOGIC.md`), який страждає на "семантичне ожиріння". Він містить живий рантайм, мертвий код (`63_necropolis`), UI-компоненти (HTML/Three.js) та важкі тіньові тести (`reduction_core`, `verification`). Це перевантажує контекстне вікно LLM (Оракула) і знижує якість генерації. 
Нам потрібно рефакторити логіку експорту (наприклад, `07_meta/02_runners/export_core.ts`), щоб вона генерувала **три окремі артефакти** з чіткими фільтрами.

## Крок 1: Оновлення логіки експортера (`export_core.ts`)
Зміни скрипт експорту так, щоб він читав файли і розкладав їх у три різні вихідні файли в `08_artifacts/`:

1. **`08_artifacts/OMEGA_RUNTIME.md` (The Live Engine):**
   - **Що включає:** Лише ядро, що приймає рішення. Директорії `00_substrate/` (крім тестів), `01_physics/`, `02_metabolism/`, `03_governance/`, `04_noosphere/`, `05_exocortex/`, `06_akasha/` (крім UI/HTML).
   - **Що виключає:** Будь-які `.html`, теку `public/`, `ui/`, всі тести (`*_test.ts`, `03_tests/`).

2. **`08_artifacts/OMEGA_SHADOW.md` (The Validation Ecology):**
   - **Що включає:** Інструменти валідації та Деміурга. Директорії `reduction_core/`, `verification/`, `07_meta/`, та всі локальні тести (`03_tests/`).
   
3. **`08_artifacts/OMEGA_LORE.md` (The Mythos & Architecture):**
   - **Що включає:** Всю документацію та маніфести. Файли `docs/**/*.md`, `*.md` в корені (крім тих, що генеруються скриптом), `deno.jsonc`, `CORE_ARCH_MANIFEST.json`.

## Крок 2: Тотальне виключення шуму (The Great Filter)
Додай жорсткі глобальні правила виключення для всіх експортів:
1. Повністю ігнорувати директорію `63_necropolis/`. Мертвий код не повинен потрапляти в контекст LLM.
2. Ігнорувати скомпільовані артефакти (всі `*.wasm`, бінарники в `.omega/`, `*.log`, `*.jsonl` з логами телеметрії).

## Крок 3: Очищення констант (LUT Truncation - Опціонально, але бажано)
Якщо скрипт експортує `00_substrate/assembly/index.ts` (або інший файл з масивами `SIN_LUT` / `COS_LUT`), додай регулярний вираз, який замінює вміст цих гігантських масивів на `/* [TRUNCATED LUT ARRAY] */`. Це зекономить тисячі токенів без втрати семантичного сенсу коду для LLM.

## Крок 4: Оновлення Deno Tasks
Переконайся, що в `deno.jsonc` є таска (наприклад, `deno task export:context`), яка запускає цей оновлений скрипт і складає готові MD-файли в `08_artifacts/`.
