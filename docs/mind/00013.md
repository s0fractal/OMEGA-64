# Phase 20: Σ-CORE The Brain Swap (WASM C-ABI Membrane)

## Контекст (Context)
Rust-двигун повністю готовий і розпаралелений. Тепер ми маємо перетворити його на "дроп-ін" (drop-in) заміну для нашого старого AssemblyScript модуля. Ми скомпілюємо `sigma_core` під таргет `wasm32-unknown-unknown` з підтримкою `SharedArrayBuffer` (atomics) і експортуємо C-сумісні функції, які вимагає `PULSE_WORKER.ts`.

## Крок 1: Налаштування WASM та Пам'яті
1. У `Cargo.toml` додай:
   ```toml
   [lib]
   crate-type = ["cdylib", "rlib"]

```

2. Створи `.cargo/config.toml` у корені `sigma_core`, щоб змусити Rust імпортувати пам'ять (як це робив Deno) і включити атомарні операції:
```toml
[target.wasm32-unknown-unknown]
rustflags = [
    "-C", "link-arg=--import-memory",
    "-C", "link-arg=--shared-memory",
    "-C", "target-feature=+atomics,+bulk-memory,+mutable-globals"
]

```


*(Примітка: для збірки знадобиться `rustup target add wasm32-unknown-unknown` та `rustup component add rust-src --toolchain nightly`, якщо вимагається перекомпіляція std для atomics).*

## Крок 2: FFI Експорти (`src/ffi.rs`)

Створи модуль `ffi.rs` (не забудь додати його в `lib.rs`).
Використовуючи `#[no_mangle] pub extern "C" fn`, експортуй точні аналоги функцій, які очікує `PULSE_WORKER.ts`:

* `execute_atom(idx: usize)`
* `tick_environment(tick: u32)`
* `tick_matrix()`
* `tick_structure_grid()`
* `build_spatial_hash()`
* `get_spatial_hash_overflow_count() -> i32`
* `get_spatial_hash_max_cell_count() -> i32`
* `reduce_atom_deltas(start_idx: usize, end_idx: usize)`
* `get_neural_coherence() -> i32`
* `set_neural_coherence(val: i32)`
* `tickGlyphTransport(tick: u32)` *(збережи camelCase для сумісності з JS)*
* `resolve_bond_requests(start: usize, end: usize) -> i32`
* `drain_spawn_requests(tick: u32) -> i32`
* `clear_metabolism_stats()`
* `accumulate_metabolism_stats(start: usize, end: usize)`
* `apply_metabolism_kernel(...)` *(з усіма 12 аргументами з `PULSE_WORKER.ts`)*

**Управління Стейтом:** Оскільки в Deno пам'ять імпортується ззовні і починається з адреси 0, ти можеш створити глобальний (або `lazy_static`) unsafe-вказівник на нульову адресу (або використовувати безпечні абстракції), щоб ініціалізувати `SigmaState` поверх імпортованої лінійної WASM-пам'яті.

## Крок 3: Інтеграційний Тест Підміни (The Drop-in Gate)

1. Онови скрипт `build_wasm.ts` (або додай новий `build_rust_wasm.ts`), щоб він викликав `cargo build --target wasm32-unknown-unknown --release` і копіював готовий `.wasm` файл у `build/release.wasm`.
2. Запусти наш головний верифікатор: `deno task test:worker-coherence:long`.
3. Якщо Deno успішно піднімає воркери, передає їм `SharedArrayBuffer`, викликає нові Rust-функції, і симуляція не падає (а хеші збігаються з еталоном) — ми успішно пересадили мозок Матриці!

## Правила (Constraints)

* Функції FFI не повинні панікувати (panic) через кордон з C. Відловлюй помилки і пиши в консоль або ігноруй, якщо потрібно.
* Переконайся, що `SigmaState` в `ffi.rs` правильно посилається на `SAFETY_BUFFER` (8_000_000), так само як це було в `assembly/index.ts`.
