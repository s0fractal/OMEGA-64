# Phase 52: The Holographic Refactoring (Barrel Files & Layer Topology)

## Контекст (Context)
Ми проводимо генеральний рефакторинг кодобази OMEGA-64 для підготовки до відкритого релізу. Ми вводимо строгу топологію директорій з префіксами (від `00_` до `63_`). 
Нова фіча: кожен шар повинен мати свій `mod.ts` (Barrel File), який експортує публічний інтерфейс цього шару. Міжшарові імпорти мають йти **виключно** через `mod.ts` сусіднього шару.

## Крок 3: Налаштування Фасадів (`mod.ts`)
У кожному `mod.ts` додай експорти всіх сутностей з цього шару, наприклад:
\`\`\`typescript
// 00_substrate/mod.ts
export * from "./OFFSETS.ts";
export * from "./STATE_MATRIX.ts";
// ...
\`\`\`

## Крок 4: Переписування Імпортів (The Great Rewiring)
Онови всі імпорти у всіх файлах. 
**Головне правило:** Якщо файл з `02_metabolism` хоче імпортувати `STATE_MATRIX`, він **не повинен** писати `import { STATE_MATRIX } from "../00_substrate/STATE_MATRIX.ts"`. 
Він **повинен** писати: `import { STATE_MATRIX } from "../00_substrate/mod.ts"`.
*(Внутрішні імпорти всередині однієї теки можуть залишатися прямими на файли, щоб уникнути циклічних залежностей всередині шару).*

## Крок 5: Архітектурний Лінтер (Topology Guard)
Створи файл `tests/architecture_guard.ts`.
Напиши простий скрипт, який:
1. Читає всі `.ts` файли у теках `00_` до `06_`.
2. Знаходить рядки з `import ... from "../XX_..."`.
3. Перевіряє префікси: якщо файл з папки `XX_` імпортує щось із `YY_`, то має виконуватися строга математична умова: `YY <= XX`.
4. Якщо умова порушена (наприклад, `00_substrate` імпортує `06_akasha`), скрипт кидає `throw new Error("Topological breach detected!")`.
5. Додай виклик цього скрипта у `deno.json` до таски `verify:coherence`.
