# Phase 32: Σ-CORE The Panopticon (Global WebGL Observer)

## Контекст (Context)

Бекенд Σ-CORE досяг стадії Golden Master: він багатопотоковий, має LLM-Оракула
та розподілену P2P-мережу. Тепер нам потрібен "Клієнт Спостерігача" (Observer
Client) — фронтенд-додаток, який підключатиметься до Deno-хоста і рендеритиме ці
500,000 атомів у реальному часі зі швидкістю 60 FPS.

## Крок 1: The Telemetry Pipeline (Бінарний Стрім)

Deno-хост не може відправляти 500,000 JSON-об'єктів по WebSocket — мережа впаде.

1. У `SWARM_NEXUS.ts` (або новому `PANOPTICON_SERVER.ts`) створи WebSocket-канал
   спеціально для UI-клієнтів.
2. Реалізуй функцію пакування кадру (`packRenderFrame`). Вона має ітерувати лише
   _живі_ атоми у `SigmaMatrix` і створювати плоский бінарний масив
   (`Float32Array` або `Int32Array`).
3. Для кожного атома передавай мінімум даних: `x, y, role/color, resonance`
   (наприклад, 16 байт на атом). Якщо живих атомів 50,000, пакет складатиме
   менше 1 мегабайта — це легко передати по WebSocket 30 разів на секунду.

## Крок 2: Setup UI Client (Three.js / A-Frame)

1. Створи папку `client/` з базовим Vite + TypeScript + Three.js проєктом.
2. Налаштуй WebSocket з'єднання до локального Deno-хоста, щоб приймати бінарні
   кадри (`event.data as ArrayBuffer`).

## Крок 3: Instanced Rendering (Магія Візуалізації)

Неможливо створити 500,000 окремих `THREE.Mesh` об'єктів. Відеокарта згорить від
кількості викликів малювання (Draw Calls).

1. Використай `THREE.InstancedMesh`. Це дозволить відрендерити всі атоми за один
   виклик до GPU.
2. При отриманні нового кадру по WebSocket, оновлюй `instanceMatrix` (координати
   X, Y, Z) та `instanceColor` (кольори на основі ролі або резонансу атома) для
   цього `InstancedMesh`.
3. Обов'язково використовуй кватерніони (`THREE.Quaternion`) для будь-яких
   обертань, як ми обговорювали раніше, щоб уникнути Gimbal Lock при русі камери
   Спостерігача.

## Крок 4: Visualizing the Neural Web (Опціонально/Бонус)

1. Якщо дозволяє продуктивність, передавай також дані про активні синаптичні
   зв'язки (`bonds`).
2. Використай `THREE.LineSegments`, щоб малювати лінії між зв'язаними атомами.
   Колір або яскравість лінії має залежати від `synaptic_weight`.

## Правила (Constraints)

- **Decoupling:** Цикл рендерингу на фронтенді (`requestAnimationFrame`) має
  бути повністю незалежним від частоти отримання даних по WebSocket.
  Використовуй лінійну інтерполяцію (Lerp) на клієнті, щоб рух атомів виглядав
  плавним, навіть якщо Deno надсилає лише 10 кадрів на секунду.
