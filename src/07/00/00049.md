### ТЗ для АГЕНТА: `docs/mind/00049.md`

```markdown
# Phase 56: The Rust Horizon (Rust-First Matrix Migration)

## Контекст (Context)
Ми переходимо на ізоморфну гібридну архітектуру (Functional Core, Imperative Shell). 
Cargo (Rust) стає головним диктатором файлової системи, тому весь код повинен жити в директорії `src/`. Deno (TypeScript) абсолютно гнучкий і підлаштується під цю зміну через оновлення `deno.jsonc`. 
Мета: створити єдиний простір, де `.ts` та `.rs` файли живуть поруч у двовимірних координатах (векторах 8x8).

## Крок 1: Cargo Ascendancy (Звільнення Ядра)
Знайди конфігураційні файли Rust (колишнього `sigma_core`), де б вони зараз не були, і перемісти їх в **Абсолютний Корінь** репозиторію:
- Перемісти `Cargo.toml` у `/Cargo.toml`.
- Перемісти `Cargo.lock` у `/Cargo.lock` (якщо є).
- Перемісти директорію `.cargo/` у `/.cargo/` (якщо є).

## Крок 2: The Great Shift (Створення Матриці)
Створи директорію `src/` в корені репозиторію.
Перемісти ВСІ векторні директорії (від `00/` до `08/` та `63/`) всередину `src/`.
*Результат: `/src/00/`, `/src/01/`, `/src/07/` тощо.*
У корені репозиторію ПОВИННІ залишитися ЛИШЕ:
- `Cargo.toml`, `Cargo.lock`, `.cargo/`
- `deno.jsonc`
- `.env`, `.env.example`
- `.gitignore`
- `README.md` (чи сімлінк)
- `docs/` (де лежать ці інструкції)

## Крок 3: Deno Page Table Update (Оновлення Мапінгу)
Відкрий `deno.jsonc` і онови всі шляхи.
1. У секції `"imports"` додай префікс `./src/` до всіх шляхів:
   `"@00": "./src/00/mod.ts"`, `"@02/01": "./src/02/01/mod.ts"` тощо.
2. У секції `"tasks"` онови всі скрипти, щоб вони вказували на файли всередині `src/` (наприклад, `deno run -A src/07/02/SYSTEM_START.ts`).

## Крок 4: Точка Збірки Rust (`src/lib.rs`)
Cargo вимагає наявності `src/lib.rs` (або `main.rs`) для компіляції.
Створи файл `src/lib.rs`. Збери в нього декларації всіх Rust-модулів, які зараз розкидані по векторах. 
Використовуй макрос `#[path]` для підключення файлів, які лежать у векторах, щоб Cargo міг їх знайти.
*Приклад `src/lib.rs`:*
```rust
#[path = "01/01/spatial.rs"]
pub mod spatial;

#[path = "02/00/pulse.rs"]
pub mod pulse;
// ... і так далі для всіх існуючих .rs файлів.

```

*(Якщо всі .rs файли ще лежать в одній купі після попереднього рефакторингу, просто переконайся, що точка входу правильно налаштована в `src/lib.rs` і компілюється).*

## Крок 5: Isomorphic Trinity (Плоский стандарт)

Перевір структуру всередині векторів (напр. `src/02/01/`).
Усі файли мають лежати ПЛОСКО (максимум 2 рівні папок: `XX/YY/`). Крім особливих випадків верифікацій та трейсів (покищо)
Зведи логічні вузли до формату "Трійці" або ідентичних префіксів:

* `map.ts` (Deno оболонка / фасад)
* `map.rs` (Rust ядро)
* `map.md` (Локальна документація/онтологія)

## Constraint Check (Критично)

1. Виконай `cargo build --target wasm32-unknown-unknown`. Помилок бути не повинно.
2. Виконай базову Deno-таску (напр. `deno task test` або запуск системи). Усі імпорти `@XX` повинні спрацювати ідеально.
