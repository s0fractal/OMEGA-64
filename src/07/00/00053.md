PROMPT FOR ANTIGRAVITY: THE GREAT MATH PURGE

CONTEXT: We are enforcing absolute determinism in the OMEGA-64 engine. Standard
library Math.* calls in TypeScript/AssemblyScript can lead to subtle
floating-point desynchronizations across platforms. We already possess
deterministic, bitwise integer variants in our L00 ontology (e.g., fast_max,
fast_min, fast_abs, math_clamp).

OBJECTIVE: Audit all pure functions in src/ontology/ (specifically autopoiesis/,
physics/, and core/) and replace all non-deterministic Math.* usage with our
deterministic equivalents.

MIGRATION RULES:

Max/Min/Abs: > - Replace Math.max(a, b) with fast_max(a, b).

Replace Math.min(a, b) with fast_min(a, b).

Replace Math.abs(a) with fast_abs(a).

Ensure you add these to the deps array in the .md frontmatter!

Math.floor & Integer Division:

Replace Math.floor(a / b) with (a / b) | 0 for i32 variables.

Replace Math.floor(x / 2) with (x >> 1).

Math.round (Fixed-Point):

If you see Math.round(a / b), rewrite it using integer math: ((a + (b >> 1)) /
b) | 0.

Clamp:

Replace Math.max(min_val, Math.min(max_val, x)) with math_clamp(x, min_val,
max_val).

Floats (f32/f64):

If a function absolutely must use floats (e.g., calculating spatial distance
Mathf.sqrt(dx*dx + dy*dy)), leave Mathf.sqrt intact for now, but eliminate any
surrounding Math.floor or Math.round by casting directly to integers (e.g.,
(distance) as i32 in Rust or distance as i32 in AS).
