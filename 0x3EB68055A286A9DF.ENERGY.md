## GREEN (G)

ENERGY Engine. Models the thermodynamic states of the OMEGA-64 organism.
Calculates energy decay based on field potential and tension, and evaluates
proactivity thresholds based on "Pain" levels.

## BLUE (B)

```typescript
/**
 * ENERGY: Thermodynamic state
 */
export const ATOM = ({ siblings: { FIELD } }) => ({
  calculateDecay: (state: any): number => {
    const potential = FIELD.FIELD.getPotential(state.r);
    return potential * (1 + (state.tension ?? 0));
  },
  getPainLevel: (state: any): number => {
    const scale = (state.energy === 0) ? 1 : state.energy * 0.1;
    return (state.tension ?? 0) / scale;
  },
});
```
