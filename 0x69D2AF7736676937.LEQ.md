## GREEN (G)

LEQ (Less than or Equal) for Church-encoded numerals. Returns TRUE if `m` <= `n`
by checking if `m - n` is Zero.

## BLUE (B)

```typescript
/**
 * LEQ: Church Encoding Less-than-or-Equal
 */
export const ATOM = ({ siblings: { IS_ZERO, SUB } }) => (m: any) => (n: any) =>
  IS_ZERO(SUB(m)(n));
```
