## GREEN (G)

L8 SIGNAL Emitter. Provides the capability specifically for Level 8 audit and
autonomy atoms to communicate directly with the Operator via the structured
`OMEGA_SIGNAL.md` ledger.

## BLUE (B)

```typescript
/**
 * SIGNAL: Operator Communication
 */
export const ATOM = () => ({
  emit: async (type: string, payload: any) => {
    const entry = `## [${
      new Date().toISOString()
    }] ${type}\n**Source**: ${payload.source}\n**Message**: ${payload.message}\n---\n`;
    await Deno.writeTextFile("./OMEGA_SIGNAL.md", entry, { append: true });
  },
});
```
