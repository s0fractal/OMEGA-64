# i/ | Invariants (Canon Core)

Purpose:
- Canonical invariants live here.
- Files in this folder are treated as stable sources of truth.
- Metadata and geometry live in annotations, not file names.

Rules:
- Each invariant file must include @omega.vector.
- Edits must be deterministic and auditable.
- No autogenerated artifacts belong here.

Rule Modules:
- Place deterministic lint rules in /i as single-purpose files.
- Example: RULE_VECTOR_REQUIRED.ts
- Additional: RULE_VECTOR_FORMAT.ts, RULE_VECTOR_RANGE.ts
- Phase mapping: RULE_VECTOR_DOMAIN_PHASE.ts
- Optional symbols: RULE_SYMBOL_OPTIONAL.ts
