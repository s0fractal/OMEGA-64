## GREEN (G)

Fundamental Wave. A continuous oscillatory function based on the sine of time
and frequency. `WAVE t freq = sin(2 * PI * freq * t)`.

## BLUE (B)

```typescript
/**
 * WAVE: Sinusoidal Primitive
 */
export const ATOM = () => (t: any) => (freq: any) =>
  Math.sin(2 * Math.PI * freq * t);
```
