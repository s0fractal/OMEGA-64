## GREEN (G)

The C Combinator, also known as the Cardinal or the Exchange operator. Swaps the
order of the two subsequent arguments before applying the function `f`.

## BLUE (B)

```typescript
/**
 * C: Exchange Combinator
 */
export const ATOM = () => (f: any) => (x: any) => (y: any) => f(y)(x);
```
