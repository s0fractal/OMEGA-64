# Experiment: The Nameless Space (e)

Exploring the 16-bit coordinate system where `Address == Essence`.

## The Axiom

- **16 Bits**: The Universe is a finite grid of 65,536 integers.
- **Structure**: `L(6) : D(6) : V(4)`
  - **L (Level)**: 0..63 (Depth/Ontology)
  - **D (Domain)**: 0..63 (Angle/Sector)
  - **V (Volume)**: 0..15 (Aperture/Width)

## Hypothesis

Names are just aliases for these coordinates. True navigation happens by
manipulating integers.
