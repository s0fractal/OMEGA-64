# OMEGA-64 | GENOME (Triplet Seed)

Purpose:

- Minimal 4-symbol seed that generates 64 levels (4^3).
- Provide deterministic mapping between levels and triplets.

Symbols:

- S, K, I, Y (ordered as S,K,I,Y)

Projections (pairing):

- S → rs
- K → ts
- I → md
- Y → q

Notes:

- This is a generator, not a gate. Validation is optional.
- Triplet order is lexicographic in the S,K,I,Y alphabet.
