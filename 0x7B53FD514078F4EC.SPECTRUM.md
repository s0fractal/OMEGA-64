## GREEN (G)

Color SPECTRUM. Generates HSL color strings based on a layer index, entropy, and
stability metrics. Used by the `HOLOGRAM` and UI to visualize system status.

## BLUE (B)

```typescript
/**
 * SPECTRUM: Semantic Color
 */
export const ATOM =
  () => (layer: number, entropy: number, stability: number): string =>
    `hsl(${Math.floor((layer / 64) * 360)}, ${
      Math.max(0, Math.min(100, Math.round(100 - entropy * 50)))
    }%, ${Math.max(0, Math.min(100, Math.round(30 + stability * 40)))}%)`;
```
