# Phase 52: Universal Octal Topology & Holographic Refactoring

## Контекст (Context)
Ми переводимо OMEGA-64 на строгу фрактальну архітектуру. Для забезпечення ідеального машинного парсингу ми вводимо Універсальний Вісімковий Словник (00-08). Кожен числовий префікс має єдине семантичне значення на будь-якій глибині дерева.
`00`=Substrate/Raw, `01`=Topology, `02`=Execution/Runners, `03`=Validation/Tests/Guards, `04`=IO, `05`=Generators/LLM, `06`=Docs/Akasha, `07`=Meta, `08`=Artifacts.

## Крок 2: Розподіл Коду (File Migration)
1. Розкидай усі робочі `.ts` файли по шарах `00`-`06` відповідно до їх ролі.
2. Ядро Rust (`sigma_core/`) -> `00_substrate/sigma_core/`.
3. Локальні тести рознеси по відповідних `XX_.../03_tests/`.
4. Скрипти збірки (`build_wasm.ts`) -> `07_meta/02_runners/`.
5. Мертвий код -> `63_necropolis/`.

## Крок 3: Налаштування Екзоскелета (`08_artifacts`)

3. У корені залиш символічне посилання: `README.md -> 08_artifacts/README.md`.

## Крок 4: Топологічний Лінтер (The Vector Guard)
1. Створи `07_meta/03_guards/topology_linter.ts`.
2. Правило парсингу: файл із префіксом `XX_` може імпортувати лише через `../YY_.../mod.ts`, де `YY <= XX`. Внутрішні імпорти всередині однієї директорії вільні.
3. Додай виклик у `deno.jsonc` як `deno task lint:topology`.
