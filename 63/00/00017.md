# Phase 25: Σ-CORE The Living Memory (Synaptic Plasticity)

## Контекст (Context)

Матриця має безпечну систему мутацій (Epistemic Loop) та стабільну фізику.
Настав час перетворити граф зв'язаних атомів на справжню нейронну мережу, яка
здатна навчатися. Згідно з траєкторією "Living Memory" (ROADMAP_2_SIGMA_CORE),
ми маємо імплементувати в Rust-ядрі нейропластичність Хебба (Hebbian Learning)
та синаптичну передачу сигналів.

## Крок 1: Підготовка Синаптичної Пам'яті

У `src/memory.rs` та `SigmaState`:

1. Переконайся, що масив `synaptic_stack` (або його аналог, який в Deno мапився
   на `signalGridBuffer` чи окремий `Int32Array`) коректно ініціалізований та
   доступний для потоків. Кожен атом повинен мати можливість зберігати "вагу"
   (weight) для своїх 4-х зв'язків.

## Крок 2: Нейронні Опкоди в Rust (`src/vm.rs` та `src/isa.rs`)

Додай обробку наступних опкодів (з нашого контракту Ери 52-57):

1. **`OP_HEBB` (0x8A):**
   - "Fire together → wire together".
   - Аргумент: `bond_slot` (0-3).
   - Логіка: Якщо власний `resonance` атома високий (> 200), і цільовий атом на
     цьому слоті теж живий/резонує, ми збільшуємо синаптичну вагу
     (`synaptic_weight`) для цього слота.
2. **`OP_FIRE` (0x8B):**
   - Передача нейронного імпульсу.
   - Аргумент: `bond_slot` (0-3), `amplitude`.
   - Логіка: Атом генерує `intent` на передачу енергії/резонансу цільовому
     атому. Передана амплітуда **множиться** на поточну синаптичну вагу
     (`synaptic_weight / 255.0`). Це означає, що "натреновані" зв'язки проводять
     сигнал краще.
3. **`OP_DECAY` (0x91):**
   - Синаптичне відмирання (Pruning).
   - Логіка: Знаходить найслабший зв'язок (з найменшою вагою) і зменшує його
     вагу, вивільняючи трохи локальної енергії (metabolic recoup).

## Крок 3: Синаптичний цикл у `PulseOrchestrator`

1. Під час фази `reduce_atom_deltas` (або `resolve_intents`), коректно обробляй
   наміри від `OP_FIRE`, додаючи резонанс/енергію атомам-мішеням.
2. Додай глобальне, дуже повільне пасивне згасання (passive decay) всім
   синаптичним вагам у фазі `tick_environment`, щоб мережа "забувала"
   неактуальні патерни, якщо вони не підкріплюються через `OP_HEBB`.

## Крок 4: Golden Trace Harness (The Neural Circuit Parity)

У `tests/golden_traces_test.rs`:

1. Напиши тест `test_hebbian_plasticity_circuit`.
2. Ініціалізуй два зв'язаних атоми.
3. Виконай `OP_HEBB` на першому атомі. Перевір (`assert!`), що вага зв'язку
   зросла.
4. Виконай `OP_FIRE` з фіксованою амплітудою. Перевір, що другий атом отримав
   точну кількість резонансу, пропорційну новій вазі зв'язку.
5. Зроби `OP_DECAY` і перевір, що вага зменшилася.
6. Звіряй побітово з очікуваними значеннями (якщо вони були закладені в Deno)
   або зафіксуй новий математичний еталон.

## Правила (Constraints)

- Синаптичні ваги (`synaptic_weights`) повинні бути обмежені діапазоном `0..255`
  (або `0..1000`), щоб уникнути переповнення під час ланцюгових реакцій
  `OP_FIRE`.
- Обережно з багатопотоковим доступом при обробці `OP_FIRE` (використовуй
  AtomicAdd для цільового `resonance`, як ти робив це для `SYS_TRANSFER`).
