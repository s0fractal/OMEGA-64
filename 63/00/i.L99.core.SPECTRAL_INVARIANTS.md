# OMEGA-64 | Spectral Invariants (Law)

Purpose:

- Fix the spectral law: canonical atoms must cohere across lenses.

Core Law:

- A canonical atom is valid only if its spectral projections converge.
- Divergence between lenses is a signal of lens impurity or drift.

Minimum:

- At least 2 lenses (projections) for canon readiness.
- Each lens produces a deterministic signature.

Signals:

- `max_delta` above threshold → spectral mismatch.
- `lens_count < min_lenses` → incomplete spectrum.
