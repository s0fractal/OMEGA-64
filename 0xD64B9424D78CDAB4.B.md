## GREEN (G)

The B Combinator, also known as the Bluebird or the Composition operator. Allows
for the chaining of functions: the result of `g(x)` is passed as input to `f`.

## BLUE (B)

```typescript
export const ATOM = () => (f: any) => (g: any) => (x: any) => f(g(x));
```
