## GREEN (G)

Machine Step operator. Consumes one unit of input and moves the machine `m` to
its next state based on its internal transition function. Produces a new MACHINE
instance with the updated state.

## BLUE (B)

```typescript
/**
 * STEP: Computational Cycle

export const ATOM = ({ siblings: { MACHINE } }) => (m: any) => (input: any) =>
  m((transition: any) => (state: any) =>
    MACHINE(transition)(transition(state)(input))
  );
```
